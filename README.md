# Honor Roll Filter

A Python program that reads student information from a CSV file and creates a new CSV file containing only students who achieved a score of 90 or above.

## Features

- Reads student data from a CSV file
- Filters students based on their scores
- Creates a new CSV file for qualified students
- Preserves original data structure using column names

## Technologies Used

- Python
- csv module
- DictReader
- DictWriter

## How to Run

1. Prepare a CSV file named `students.csv`

Hermione,Gryffindor,99
